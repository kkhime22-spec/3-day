# 저니맵 — 한 사람 · 한 시나리오 (M5-04)

> 페르소나(정민, docs/persona.md)를 기준으로 한 시나리오입니다. 모든 칸은 (가설)이며, 실제 사용자 관찰로 검증 전입니다.

- 시나리오: 정민이 주말에 청약홈을 몰아 보다가 관심 단지 공고를 발견하고, 그 단지에 도전할 수 있을지(자금이 되는지) 판단하려는 과정
- 처음 들어오는 순간: 주말에 청약홈에서 관심 단지(예: 서울 SH 공공분양) 공고를 우연히 발견한 순간
- 마지막에 얻는 것: "이 단지에 지금 도전 가능한지(내 현금+대략적 대출 여력으로 감당되는지)"에 대한 대략적인 답과, 다음 행동(준비 지속 vs 다른 단지·연도 재검토)에 대한 판단 근거

|단계|행동|생각|감정 1~5|다음 단계로 가는 이유|기회|
|---|---|---|---|---|---|
|1. 발견|주말에 청약홈을 몰아 훑어보다 관심 단지 공고를 발견한다|"오, 이거 괜찮아 보이는데?"|4|관심이 생겨 조건(주택형·세대수·시기)을 더 자세히 보고 싶어진다|공급 일정을 한 화면에 정리해 보여주면 탐색 시간이 준다|
|2. 조건 확인|관심 단지의 주택형·공급 세대수·공급 예정 시기를 확인한다|"이 정도면 나도 넣어볼 수 있나?"|3|실제로 감당 가능한지 알아야 다음 결정을 할 수 있다|주택형을 고르면 바로 다음(자금 확인) 단계로 이어주는 흐름|
|3. 자금 계산 시도 ★최저점|필요한 최소 자금이 얼마인지, 내 현금·대출로 감당되는지 직접 계산해보려 한다|"이거 얼마나 있어야 되는 거지... 계산이 너무 복잡하다"|1|답을 못 찾으면 포기하거나 은행 상담을 따로 예약해야 해서(시간 소모) 다음 단계로 못 넘어간다|보유 현금·월소득을 입력하면 참고 대출금리(D2)로 개산한 "대략적 자금 여력"을 즉시 보여주는 계산기 → F-01 후보|
|4. 판단|개산 결과(가능/부족)를 보고 준비를 계속할지, 다른 단지·연도를 볼지 정한다|"이 정도면 해볼 만하네" 또는 "조금 더 모아야겠다"|4|판단 근거가 생겨야 계획을 구체적으로 세울 수 있다|판단 결과를 화면에 남겨 다른 주택형·연도와 바로 비교해볼 수 있게 함|
|5. 재확인 (선택)|다음 공고가 나올 때 다시 들어와 비교한다|"다음 것도 여기서 확인해야지"|4|재방문 습관이 생기면 다음 공고도 놓치지 않는다|관심 단지·연도 즐겨찾기(오늘 범위 밖, 가설)|

- 감정 최저점: 3단계(자금 계산 시도) → 기능 후보: 보유 현금·월소득 입력 시 참고 대출금리 기준으로 개산한 자금 여력을 즉시 보여주는 계산기 (F-01 핵심 기능과 직결)
- 떠나는 순간: 3단계에서 계산이 복잡하거나 결과가 바로 안 나와서 포기하고 앱을 닫는 순간
- 붙잡을 장치: 입력 항목을 최소화(보유 현금·월소득 정도)하고, 빈값이어도 즉시 안내를 보여줘 "계속 만지면 답이 나온다"는 느낌을 준다
